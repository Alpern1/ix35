# Ön + arka dashcam (parkta da kayıt)

> **Durum:** 📋 Kenarda — fiyat yüksek; sonra dönülecek  
> **Son konuşma:** 2026-08-12

## İhtiyaç (kilitli)

| Madde | Karar |
|-------|--------|
| Amaç | **Kayıt / kanıt** — geri görüş park kamerası değil |
| Park | Araç parkta da izlensin (park modu) |
| Bütçe | Fiyat/performans; şu an pahalı geldi → beklet |
| Kablo | Ortada / çakmakta istemiyor → **hardwire + trim altına gizle** |
| Görünüm | Önde arkada **büyük gövde istemiyor** (ekranlı şişkin modeller ele) |

## Kenara alınan öneriler

### Görünüm öncelikli (daha pahalı)
- **BlackVue** 2 kanallı (DR750-2CH / güncel muadil) + hardwire — ince “puro” gövde, ekransız
- **Thinkware** F200 PRO / U1000 tipi — benzer gizlilik

### Daha ucuz ama yine görece küçük
- **70mai M500** + arka kamera + **UP03** park kablosu

### Ele (büyük görünüm)
- 70mai **A810** / **A510** (2–3" ekran, şişkin)
- Büyük ekranlı ayna tipi setler (bu ihtiyaç için değil)

## Kurulum notu (ileride)

1. Ön: cam üstü, mümkünse dikiz arkası / yanına, kompakt  
2. Arka: **arka cam içi** küçük ünite (bumper dış kamera değil)  
3. Arka kablo: tavan kenarı / lastik altı → ön ünite  
4. Güç: sigorta kutusu ACC + B+ + şasi; hardwire’da düşük voltaj kesici ~**12.2–12.4 V**  
5. SD: 128–256 GB High Endurance  

Parkta genelde tam 7/24 full değil → darbe/hareket veya time-lapse.
