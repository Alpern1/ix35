# Nasıl yaparız — ön ayrı, yan ayrı

> Şartlar: açıkken güneşi iyi kessin · kapalıyken yama/fazlalık gibi durmasın · motorsuz · TR’den bulunur olsun

---

# A) ÖN CAM

## Ne işe yaramalı?

| Durum | Beklenti |
|-------|----------|
| **Açık (park)** | Ön camı mümkün olduğunca tam örtsün; dış yüz yansıtıcı veya yoğun opak → torpido/direksiyon yanmasın (klasik güneşlik seviyesi) |
| **Kapalı (sürüş)** | Camın ortasında şişkin tüp / vantuz ormanı olmasın; görüşü kesmesin; “sonradan takılmış yama” hissi vermesin |

## TR’de görülen tipler (araştırma)

### Tip Ö1 — Yan kaset + geri sarımlı (ör. Baseus Auto Close CRZYD)

| | |
|--|--|
| Örnek | Baseus CRZYD-B0S 64 cm sınıfı · **2026-08-12 TR stok yok** — alış linki yok; Sepete ekle görünce al |
| Açık | Dış alüminyum folyo + iç siyah kumaş → **ısı kesimi iyi** (orijinal katlanır güneşliğe yakın mantık) |
| Kapalı | Yolcu tarafında ~64 cm dikey tüp + 2 vantuz; karşıda sabitleme vantuzu kalabilir |
| Montaj | Camı sil → tüpü yolcu kenarına vantuzla → parkta çek → karşı vantuz/kancaya tut |
| Kapalı görünüm dürüstlüğü | **Tamamen görünmez değil.** İyi yerleşirse A sütunu / cam kenarı hizasında “ince şerit” olur; ortaya koyarsan yama gibi durur |
| Not | “Otomatik” = yaylı geri sarma, **motor değil** |

**Nasıl kötü durmaz?**
- Tüpü camın **en kenarına**, siyah seramik bant / A sütunu hizasına yapıştır
- Karşı vantuzu da kenarda tut; cam ortasına yapıştırma
- Mümkünse sürüşte karşı vantuzu söküp torpido gözüne at (tüp kenarda kalır) — daha temiz

### Tip Ö2 — Altta duran teleskopik / “şemsiye” tüp

| | |
|--|--|
| Örnek | “70×120 ayarlanabilir”, “çift çubuk pencere şemsiyesi” sınıfı (otoaksesuarcim vb.) |
| Açık | Genişlik ayarlı, kaplama iddiası yüksek |
| Kapalı | Çoğu model **torpido üstü / cam alt kenarı**nda kalır → kalabalık, fazlalık hissi güçlü |
| Bu proje için | **Ele** — kapalı halde senin “yama/fazlalık olmasın” şartına aykırı |

### Tip Ö3 — Custom yan–yan kaset (yurt dışı, Dash Designs tipi)

| | |
|--|--|
| Kapalı | ~1.5" kaset A sütunu yanında — bu sınıfta **en az göze batan** sabit çözüm |
| Açık | Yansıtıcı kumaş, ısı kesimi iddiası yüksek |
| TR | Direkt rafta zor; Amazon/US + kargo/gümrük |
| Şimdilik | İdeal görünüm referansı; ilk deneme TR Tip Ö1 |

### Tip Ö4 — Katlanır custom panel (Snap Shades / Tucson 2010–15)

Açıkken en iyi örtü olabilir; kapalıyken bagajda → her sefer tak-çıkar. **Hedef dışı** (nefret edilen ritüel).

## Ön cam — pratik yapım sırası

1. Ön cam iç genişlik ölç (A–A, dikiz altından) + yükseklik  
2. TR’den **siyah/gri geri sarımlı yan kaset** al — yalnızca **Sepete ekle** stoklu (Baseus sınıfı; SUV için ~64 cm)  
3. Deneme montaj: sadece **kenar**, 1 park günü  
4. Açıkken boşluk / ışık kaçağı var mı bak  
5. Kapalıyken sürücü koltuğundan foto — “fazla mı duruyor?”  
6. Beğenmezsen sök (vantuz izi: ılık su + cam sil) → başka boy/marka veya sonra Tip Ö3

**Dürüst sınır:** Vantuzlu her ürün kapalıyken bir miktar “aksesuar” kalır. “Sanki hiç yokmuş” istiyorsan tek yol sürüşte tamamen sökmek — o da katlanır güneşlik ritüeline yaklaşır. Hedef: **kenarda ince, ortada yok**.

# B) YAN CAMLAR

## Ne işe yaramalı?

| Durum | Beklenti |
|-------|----------|
| **Açık (park)** | Camı kaplasın; park ısısı + mahremiyet (file bebek perdesi yetmez — **opak/siyah stor**) |
| **Kapalı (sürüş)** | Cam ortasında kaset + 3 vantuz “yama” olmasın; kapı açılınca sürtmesin; mümkünse üst çerçeveye yaslansın |

## TR’de görülen tipler

### Tip Y1 — Makaralı vantuzlu stor (Carub / jenerik 2’li)

| | |
|--|--|
| Örnek | Carub otomatik makaralı yan cam perde 2’li **40×45 cm** (Trendyol, yokyokoto…); “makaralı 2’li” Allesgo/Cander vb. ~40–45 cm |
| Açık | Aşağı çek, vantuz/cırt ile tut → parkta güneş keser (opak olanlar) |
| Kapalı | İnce yatay kaset camda kalır |
| Montaj | Deliksiz; kapı plastiğine dokunmaz |
| Risk | Ölçü küçük kalırsa kenarlarda ışık kaçağı; kaset **cam ortasına** yapışırsa yama gibi |

**Nasıl kötü durmaz?**
- Kaseti camın **üst kenarına** (çerçeveye bitişik) koy — OEM arka stor hissi  
- Siyah kaset + siyah kumaş; metal çerçeveli renkli “bebek seti” alma  
- **Cam indirme:** Kaset cama yapışıksa camla birlikte iner → normal cam kullanımı **yok**; cam açacaksan sök  
- ix35 arka kapı camı ~40×45’ten büyük olabilir → **ölç, büyük beden ara** (45–50+ cm genişlik)  
- Ön kapı camları şekilli (üçgen) — tek ölçü her kapıya oturmayabilir; gerekirse ön/arka ayrı ölçü

### Tip Y2 — Düz vantuzlu file / tül perde

| | |
|--|--|
| Örnek | Piranha 11250, Carub düz vantuzlu siyah set |
| Açık | Işık geçer, ısı kesimi zayıf |
| Kapalı / açık | Hep “aksesuar” durur |
| Bu proje | **Park ısısı için ele** (sadece mahremiyet/çocuk yolculuğu işi) |

### Tip Y3 — Sıkıştırma ayaklı / üst kenar kancalı makara

| | |
|--|--|
| Artı | Vantuz izi az; üst çerçeveye oturursa daha az “orta cam yaması” |
| Eksi | ix35 lastik/çerçeve uyumu deneme-yanılma |
| Tercih | Y1 ile aynı alışverişte “vantuz + sıkıştırma ayak” yazan setleri seç |

## Yan — pratik yapım sırası

1. Bir **arka** kapı camı iç ölçü (genişlik × yükseklik, düz kısım)  
2. Bir **ön** kapı camı ölçü (şekil farklı)  
3. 2’li siyah makaralı set × 2 (önce arka 2’yi dene)  
4. Montaj: kaset **üste**, cam temiz/kuru  
5. Kapı tam kapanıyor mu? Cam açma ihtiyacı varsa: kaset cama yapışıkken **normal cam yok** — kabul mü?  
6. Kapalı foto: dışarıdan + içeriden — kaset çerçeveyle bir mi, ortada mı?  
7. Beğenince ön kapılara geç / ölçü uymuyorsa ayrı beden

**Dürüst sınır:** Yan stor kapalıyken camın üstünde ince bir çubuk kalır. Bu, fabrika arka stor’dan daha görünür olur ama **doğru yerleştirilirse** “üstte ince çizgi” olur, “camın ortasında yara bandı” olmaz.

# C) Açıkken “orijinal gibi” güneş kesmek

| | İyi keser | Zayıf keser |
|--|-----------|-------------|
| Ön | Folyo dış + yoğun iç (Baseus sınıfı) veya kalın yansıtıcı kumaş | Gözenekli/file “nefes alan” perde |
| Yan | Opak siyah stor | Mesh bebek file |
| Ortak | Camı **tam kaplayan** ölçü; kenar boşluğu az | Küçük beden, ortada asılı |

“Orijinal katlanır güneşlik” ısı performansı ≈ yansıtıcı tam kaplama. Tip Ö1 bunu hedefler. File/perfore (Sunup gözenekli vb.) mahremiyet verir, **fırın etkisini** aynı kesmez → park ana hedefinde önemseme.
