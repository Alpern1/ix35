# Ön cam — nasıl yapılıyor? (araştırma)

> Sadece park. Sürüşte örtülü gitmek yok.

---

## Piyasada gerçekten ne var?

İnsanların “ön cama perde” dediği şey aslında **3–4 ayrı ürün sınıfı**. Karışmasın:

### 1) Yan–yan çekmeli roller (en “sabit güneşlik” hissi)

**Örnek tip:** Dash Designs “The Shade” / benzeri custom retractable.

| | |
|--|--|
| Ne | İnce kaset (~1.5") yolcu tarafı cam/A sütunu yanında; tutamaktan çekince kumaş **dikiz aynasının etrafından** sürücü tarafına gelir, brakete kilitlenir |
| Montaj | 3 braket, **ön camın iç yüzeyine** yüksek ısı 3M bant — alet yok, kapı/torpido sökme yok |
| Kalıcılık | Braketler camda kalır; kaset istenirse braketten çıkar |
| Hasar | Plastik kapıya dokunmaz. Bant sökülürse camda yapışkan kalabilir (ısı+alkol ile temizlenir) |
| ix35 | Custom-fit listelerde Tucson/ix35 kuşağı için ürün aranır; yoksa ölçülü universal |
| Artı | Bagaja atılmaz; her parkta 2 sn; katlanır karton ritüeli yok |
| Eksi | Camda hep ince kaset/braket görünür; TR’de marka/tedarik zor olabilir; 24 saat bant kür |

Üretici uyarısı (tipik): **örtülü sürülmez**.

```
[Yolcu A-sütunu]  kaset |========kumaş========|  kilit  [Sürücü A-sütunu]
                              ↑ parkta açık
                         dikiz aynası etrafından
```

### 2) Vantuzlu / kancalı “otomatik geri sarımlı” universal (TR’de bol)

Trendyol / oto aksesuar: Baseus Auto Close, Sunup geri sarımlı, “otomatik teleskopik” vb.

| | |
|--|--|
| Ne | Metal/PVC tüp + yay; çekince açılır, bırakınca toparlanır |
| Montaj | Vantuz cama **veya** alt kenara / siperlik kancası — modele göre |
| Yön | Çoğu pratikte **yukarı–aşağı** veya çapraz gerilim; bazıları altta durur yukarı uzar |
| Artı | Ucuz, iz bırakmadan sökülür, kapıya sıfır müdahale |
| Eksi | Vantuz yazın düşer / iz bırakır; “OEM perde” gibi durmaz; ölçüsü ix35 camına tam oturmayabilir; ucuzları çıngırdar |

**Senin “göze batmayan sabit” hedefine 1 daha yakın; 2 daha “aksesuar”.**

### 3) Custom katlanır / rulo panel (ix35’e özel var)

Snap Shades, YelloPro vb. — **2010–2015 Tucson/ix35** için kesilmiş yansıtıcı panel.

| | |
|--|--|
| Ne | Parkta cama yasla, siperlikleri indir; bitince katla/rula at |
| Artı | En iyi ısı kesimi genelde bu sınıfta; model-specific |
| Eksi | **Nefret ettiğin sınıf** (her seferde tak-çıkar, bagajda yer) |

Araştırmada not: “retractable” yazıp aslında katlanır satan ilanlar var — isme bakma, mekanizmaya bak.

### 4) Motorlu / elektrikli ön cam stor

Tesla Model 3/Y için vantuz+OBD motorlu kitler var. **ix35’e hazır motorlu kit yok.**  
Kendin motor+ray = tavan döşemesi, güç, güvenlik — bütçe/DIY olarak şimdilik **elendi**.

---

## “Yukarı inen perde” hayali vs gerçek

OEM arka cam stor: tavan/üst çerçevede kaset, **aşağı iner**.  
Ön camda aynı şey:

- Fabrikadan ix35’te yok  
- Aftermarket’te nadir / pahalı / modele özel  
- Pratik aftermarket ön çözümler ya **yan–yan roller (sınıf 1)** ya **vantuzlu tüp (sınıf 2)**

Yani “arka camdaki gibi yukarıdan inen” ön için **hazır temiz çözüm zayıf**; en yakın hissiyat **sınıf 1 (yan–yan ince kaset)**.

## Görüş engeller mi?

| Durum | Engeller mi? |
|-------|----------------|
| Parkta açık | Evet — zaten amaç |
| Sürüşte kaset toplanmış | Hayır (ince şerit A sütunu yanında; dikiz/görüşe girmez diye konumlanır) |
| Sürüşte unutulmuş açık | **Evet, tehlikeli / yasal sorun** |

Alışkanlık: kapıyı açar açmaz / kontaktan önce topla. Bu, katlanır güneşliği çıkarmaktan kolay.

---

## ix35 için pratik öneri sırası

1. **Öncelik A:** Custom veya iyi ölçülü **yan–yan retractable** (kalıcı braket cama) — “sabit” hissi  
2. **Öncelik B:** Kaliteli vantuzlu geri sarımlı (TR stok) — önce dene, beğenmezsen iade  
3. **Alma:** Motorlu DIY, sağ–sol iki kanatlı “perde rayı”, ucuz gümüş folyo çadır  

Ölçü (sipariş öncesi): ön cam iç genişlik (A–A sütunu) + yükseklik (torpido üstü–tavan). Foto + mezura yeter.
