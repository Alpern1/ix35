# Yan cam — cam serbest kalan tasarımlar

> Düzeltme (2026-07-26): Ucuz vantuzlu makara “aptal” değil park oyuncağı; **cam serbest** isteyen tasarım ayrı aile.  
> Senin ix35 (2010–2015) için çerçeve montajlı ürün **gerçekten var**.

## Kısa cevap

| Soru | Cevap |
|------|--------|

---

## İki aile (karıştırma)

```
A) CAMA tutunan          → kaset/camla iner → cam normal KULLANILMAZ
   Carub / Buffer / Allesgo “vantuz veya sıkıştırma → cam üzerine”

B) ÇERÇEVEYE tutunan     → cam bağımsız iner → cam KULLANILIR
   Car Shades klips · Snap/Trokot mıknatıs · conta/fitil çubuğu
```

Allesgo metni açık: *“vantuzlarla veya sıkıştırma ayaklarıyla **cam üzerine** sabitleyin.”*  
Sıkıştırma ayağı sihirli çerçeve montajı değil — çoğu üründe yine **cam kenarı**.

---

## B ailesi — nasıl çalışır?

Sabit parça, camın kaydığı yüzeyde değil; **kapı pencere açıklığının çerçevesinde** (metal trim, lastik arkası, yapışkan mıknatıs plakası, klips).

```
Çerçeve (sabit) ── tutucu (klips/mıknatıs)
Cam (hareket)   ── serbest kayar (gölgelik yerinde kalır)
```

Üretici iddiası (ör. Car Shades / Blinds4cars / Snap Shades):  
*camı indirebilirsin, gölgelik durur.* Yüksek hızda tam açık camda emilme riski → genelde **yarıya kadar** önerilir.

## Park ısısı vs cam serbest (dürüst trade-off)

| | A — cama makara (Carub) | B — çerçeve mesh (Car Shades/Snap) |
|--|-------------------------|-------------------------------------|
| Cam kullanımı | Kaset dururken **hayır** | **Evet** (kısmi/tam, ürüne göre) |
| Park siyahlık / ısı | Opak stor → daha iyi | Mesh → ışık/ısı **sızar**; park blackout değil |
| Görünüm | Üstte tüp | Çerçevede file panel |
| TR ucuz stok | Bol | Zayıf; genelde UK/EU sipariş |
| Kapı plastiği vida | Yok | Yok (klips/bant/mıknatıs) |

Senin hedef **park ısı + sabit + cam normal** ise:
- Saf A (vantuz makara) → ısı iyi, cam kötü  
- Saf B (çerçeve mesh) → cam iyi, park blackout zayıf  
- İkisini birden bekleyen ucuz TR “sihirli makara” pratikte yok

OEM kapı içi stor (Mercedes vb.) camdan bağımsızdır ama aftermarket DIY + vida/sökme ister — senin “kapıya vida yok” ile çelişir.

## Ne alma / ne dene

**Alma (cam serbest sandığın):**  
“Sıkıştırmalı makaralı 2’li” + metinde *cam üzerine* → hâlâ A ailesi.

**Dene (cam serbest istiyorsan):**  
1. ix35 2010–2015 **araç özel** çerçeve klips / mıknatıs set (Car Shades / Snap / Trokot sınıfı)  
2. Tek arka kapıda dene: cam yarı/full inme, kapı kapanma, rüzgârda düşme  
3. Park ısısı yetmezse: ön için ayrı opaque çözüm; yan mesh’i “sürüş + hafif park” kabul et  

**Hibrit (mümkün):**  
Parkta opaque panel/tak-çıkar veya ön kaset; yanlarda çerçeve mesh — cam özgürlüğü yanlarda.
