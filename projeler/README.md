## Yeni proje açmak

1. [\_sablon.md](_sablon.md) kopyala → `projeler/<isim>.md`
2. Bu tabloya **Ana projeler** satırı ekle
3. [degisiklikler.md](../degisiklikler.md) not düş

**Örnek:** `cam-filmi.md`, `bagaj-organizer.md`, `multimedya-degisimi.md`
