## Yağ filtresi

| | |
|--|--|
| Tip | Vidalı (spin-on) kartuş değil |
| OEM | **26300-35503** |
| İyi muadil | Mann **W811/80**, Bosch, Mahle OC707, Filtron, Wix… |
| Fiyat bandı TR | ~150–350 TL |

Her değişimde **filtre + tapa contası (crush washer)** yenile.

Drenaj tapası genelde **M14×1,5**; tork yaklaşık **34–44 Nm** (sıkı ama dişi sıyıracak kadar değil). Conta yenilemeden sıkma.

## Alet — ne lazım?

### Zorunlu (güvenlik)

| Alet | Şart mı? | Not |
|------|----------|-----|
| **Kriko** | Evet | Senin bildiğin |
| **Kriko sehpası (jack stand) ×2** | **Evet** | Sadece kriko ile altına **girilmez**. Sehpa şart. |
| Tekerlek takozu | Evet (veya taş/kalas) | Arka tekerleri sabitle |
| Düz / sert zemin | Evet | Eğimli yol yok |

Sehpasız “biraz kaldırıp uzanayım” = kaza riski. Sehpa yoksa işi ertele veya lastikçi/usta liftinde yaptır.

### Zorunlu (iş)

| Alet | Not |
|------|-----|
| Yağ boşaltma kabı | ≥5 L |
| Lokma + cırcır | Tapa için çoğu Hyundai’de **17 mm** (arabada doğrula) |
| **Yağ filtresi anahtarı** | Kayış / zincir / kapak tipi — el yetmezse şart |
| Huni | Doldururken |
| Eldiven + bez / kağıt | Kirli iş |
| Torx / 10 mm lokma seti | Alt muhafaza (karter muhafazası) vidası varsa |

### İyi olur (ucuz / bir kez al)

| Alet | Not |
|------|-----|
| Tork anahtarı | Tapa 34–44 Nm; yoksa “sağlam + 1/4 tur” ama dişi sıyırma |
| Fener / kafa lambası | Altı karanlık |
| Araç rampası (opsiyonel) | Sehpa yerine bazıları rampa kullanır; yine takoz |

## Ucuz nasıl?

| Kalem | Ucuz yol |
|-------|----------|
| Yağ | 4 L kutu kampanya (Koçtaş / BM / Trendyol); “bakım seti” bazen filtre+yağ paket |
| Filtre | Mann/Bosch muadil; orijinal şart değil |
| Conta | Nalbur / yedek parça — birkaç TL |
| Sehpa | 2’li set bir kez al (~500–1500 TL bandı) → sonraki bakımlarda bedava işçilik |
| Filtre anahtarı | Ucuz kayış tipi yeterli |
| Yağ atığı | Belediye / akaryakıt istasyonu / sanayi — dökmeyi yasak |

İlk sefer alet + yağ ≈ usta işçilikten pahalı gelebilir; **2. değişimden itibaren** net kâr.

---

## Adımlar (kısa)

1. Motoru **ılık** yap (5–10 dk), düz zemin, el fren, vites 1 veya R, takoz.
2. Önden kriko → **sehpalara oturt**, kriko yedek kalabilir.
3. Alt muhafaza varsa sök.
4. Kaputtaki yağ kapağını **aç** (vakuum için).
5. Kabı koy → drenaj tapasını sök → boşalt → **yeni conta** + tapa sık (~34–44 Nm).
6. Filtreyi sök (anahtar) → contayı yağla → yeni filtreyi **el sıkı + ¾ tur** (talimata göre).
7. Muhafazayı tak → arabayı indir.
8. ~3,3 L koy → çalıştır 10 sn → kapat → 2 dk bekle → çubukla **F’ye yaklaştır**, üstüne çıkarma. Toplam ~3,6 L.
9. Altı sızıntı kontrol. 50–100 km sonra tekrar seviye bak.

---

## Dikkat

- Sadece kriko ile altına yatma.
- Contasız tapa / aşırı sıkma → sızıntı veya diş sıyırma.
- Fazla yağ → zarar; çubukla azar azar.
- LPG: yağ aynı; aralığı biraz sık tut.
- Eski yağı doğaya / çöpe dökme.
