# Kullanım Senaryoları — İnme & Binme

> Sistem kurulu ve çalışıyor varsayımıyla. Manuel vites + Smart Key + START/STOP.
> Her parktan sonra aynı prosedür — "istersen istemezsen" yok.

---

## A) ARAÇTAN İNME (park ediyorsun)

### Şu an yaptığın (sistem yokken)

```
Vites boş → El freni → START/STOP'a bas → motor KAPANIR → İn
```

### Sistem kurulduktan sonra (her seferinde böyle)

```
1. Yere park et
2. Vitesi BOŞA al
3. El frenini ÇEK
4. Debriyaj ve frenden ayağını çek
5. START/STOP'a BASMA ❌  (motoru sen kapatmıyorsun)
6. Uzaktan çalıştırma kumandasında START tuşuna 2.5 saniye bas
   → Motor ÇALIŞIR KALIR (rölantide)
7. Araçtan İN (motor hâlâ çalışıyor)
8. Kapıyı KAPAT
9. Motor KENDİ KAPANIR + kapılar KİTLENİR + sistem "hazır" moduna geçer
```

**START/STOP'a basmayacaksın.** Motor çalışırken inip kapıyı kapatıyorsun; sistem motoru kapatıp kendini hazırlıyor.

**Neden böyle?** Manuel viteslerde "vites boşta mı?" sensörü yok. Sistem şunu doğruluyor: "Motor çalışırken çıktıysan vites boş olmalı, yoksa hareket ederdin." Bu güvenlik prosedürü.

**Unutma:** Kapıyı kapatmadan önce biri kapıyı açarsa veya prosedür yarım kalırsa sistem silahlanmaz → o gece uzaktan çalışmaz.

---

## B) SABAHA / UZAKTAN ÇALIŞTIRMA (evden, telefondan)

```
1. Telefon uygulamasını aç
2. "Çalıştır" (Start)
3. Motor çalışır (benzinle — Prins böyle başlar)
4. Klima son bıraktığın ayarda devreye girer (AUTO + sıcaklık)
5. Dörtlüler yanıp söner (çalışıyor göstergesi)
6. 10–15 dakika sonra araca git
```

---

## C) ARACA BİNME (uzaktan çalıştırılmış araç)

```
1. Telefon veya kumanda ile kilidi AÇ
2. Kapıyı aç — motor çalışıyor (rölantide)
3. Bin (smart key cebinde)
4. FRENE bas
5. START/STOP'a BİR KEZ bas (sistemi devral — motor çalışmaya devam eder)
6. Debriyaja bas → vitese al → sür
```

**Not:** Frene basmadan vitese alma. START/STOP'a basmak "devralma" — motoru kapatmıyor, kontrolü sana veriyor.

---

## D) NORMAL SÜRÜŞ SONRASI TEKRAR (özet döngü)

```
[Sürüş] → [Park] → [Boş vites + el freni] → [Kumanda START 2.5sn]
    → [Motor çalışırken çık] → [Kapı kapat] → [Motor kapanır, sistem hazır]
        → [Evden telefonla çalıştır] → [Bin, frene bas, START/STOP, sür]
```

---

## E) Walk-away otomatik kilit (ayrı modül — varsa)

Bu uzaktan çalıştırma prosedüründen **bağımsız**:

```
Normal inersin (START/STOP ile kapatırsın veya yukarıdaki prosedür)
Anahtar cebinde uzaklaşırsın → kapılar kilitlenir
Geri gelirsin → kapılar açılır
```

Walk-away modülü varsa bile **uzaktan çalıştırma günü** yine Bölüm A prosedürünü yaparsın.

---

## F) Sık karışan noktalar

| Soru | Cevap |
|------|-------|
| İnerken START/STOP'a basar mıyım? | **Hayır** — kumanda START 2.5 sn |
| Motor çalışırken iner miyim? | **Evet** — kısa süre, kapı kapanınca durur |
| Araba uzaklaşınca kapanır mı? | Walk-away ayrı; uzaktan çalıştırma hazırlığında kapı kapanınca motor durur |
| Binerken START/STOP? | **Evet** — frene bastıktan sonra bir kez (devralma) |
| Her gün aynı mı? | **Evet** — her parkta A prosedürü |
