# DIY kurulum — kendin yap (ana yol)

> Karar: Kayseri’de doğru usta yok → malzeme + sen.  
> Araç: 2012 ix35 · ısıtma var · deri muhtemelen deliksiz

---

## Senin yapacağın iş (özet)

```
1. Kit gelince masada test (ses, kademe)
2. Şoför koltuğunu sök
3. Kılıfı aç (klips/hog ring — video izle)
4. Isıtma matını KESMEDEN kenara al / işaretle
5. Süngere fan yuvası + hava delikleri kes
6. Fanları sabitle, kabloyu koltuk altına çıkar
7. Mesh koy, ısıtmayı geri yerleştir (hava yolu açık)
8. Deriyi del (şablon) VEYA delikli panel ekle
9. Kılıfı kapat, koltuğu tak
10. ACC + sigorta + anahtar
11. Test → sonra yolcu koltuğu
```

Airbag kablosu / yan airbag konnektörü: sökerken foto çek, aynı yere tak. Sarı fişlere zorlama.

---

## Zorluk (dürüst)

| İş | Zorluk | Sen |
|----|--------|-----|
| Koltuk sök-tak | Kolay-orta | Yapılır |
| Elektrik (ACC, sigorta, switch) | Orta | Yapılır (multimetre) |
| Sünger kes + fan göm | Orta | Yapılır |
| Kılıf sök-tak | Orta | Video + sabır |
| Deri düzgün perforasyon | Orta-zor | Şablon şart; kötü delik çirkin görünür |
| Sıfırdan kılıf dikmek | Zor | **Yapma** — mevcut kılıfı kullan |

## Malzeme (hatırlatma)

Detay: [malzemeler.md](malzemeler.md)

- Embedded kit (5–7 fan, 3 kademe, rocker) — **1 koltuk sample önce**
- Sigorta + röle
- (Gerekirse) reticulated foam
- Deri delme şablonu / punch seti

Gümrük can sıkar ama usta alternatifi yoksa bu bedel.
