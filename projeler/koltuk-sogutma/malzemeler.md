## 1) OEM blower — ne mümkün?

### A) ASPINA (gerçek fabrika fanı)

- Hyundai/Kia vb. OEM’lere blower satan üretici  
- Sessiz, ince (15–23 mm), PWM, ~49–57 dB(A) lab  
- Site: [aspina-group.com — seat ventilation blower](https://www.aspina-group.com/en/products/motors/cat15/)  
- **Satış:** Genelde üreticiye / büyük sipariş. Bireysel “sepete ekle” yok; inquiry / prototype  
- Sonuç: “ASPINA alayım bitsin” pratik değil (şimdilik)

### B) Hyundai orijinal koltuk blower (yedek parça)

Örnek parça numaraları (yeni nesil Tucson/Santa Fe/Sonata — **ix35 LM değil**):

| Parça | Ne | Kabaca fiyat (USD liste) |
|-------|-----|---------------------------|
| **88550-C5AD0** | Ön oturma (cushion) ventilation blower | ~200–300 USD / adet |
| **88551-D3000** | Benzer cushion blower (Tucson 2016–21 vb.) | benzer |

Kaynak örnek: [hyundaipartsdeal 88550-C5AD0](https://www.hyundaipartsdeal.com/genuine/hyundai-blower-unit-fr-cush-venti~88550-c5ad0.html)

**Artı:** Gerçek OEM sessizlik/kalite  
**Eksi:**  
- Sırt için ayrı blower / kanal da lazım (koltuk başına genelde 2 ünite)  
- Konnektör, bracket, sünger oyuğu ix35’e **uymaz** → usta uyarlar  
- 2 koltuk × 2 blower ≈ **parça tek başına 800–1200+ USD** + gümrük  
- Anahtar, mesh, delikli deri ayrıca  

**Ne zaman mantıklı?** Sessizlik takıntısı + bütçe yüksek + usta OEM parçayı süngere gömebilir.

### C) Hurda / çıkma ventilated koltuk blower

eBay / hurda: “seat ventilation blower Hyundai”  
Ucuz olabilir; ömür/ses belirsiz. Deneme için, garanti yok.

## 2) En gerçekçi yol — profesyonel aftermarket kit

Çin’de koltuk üreticilerine satılan **iç montaj kitleri** (minder değil):

### Tipik paket içeriği

| Malzeme | Ne işe yarar |
|---------|----------------|
| 5 veya 7 adet **12V turbo/blower fan** (koltuk başı) | Oturma 3 + sırt 2 (veya 7) |
| PWM / 3 kademe kontrol kutusu | Sessiz–orta–yüksek |
| OEM tarzı **rocker switch** | Isıtma yanına gömülür |
| Kablo demeti + sigorta | ACC 12V |
| (İyi kitlerde) reticulated / mesh foam | Hava yayıcı |
| (Opsiyonel) delikli ısıtma matı | Eski mat hava kesiyorsa |

Örnek üretici / kanal:
- [Jiuyi / Huixinyi — car seat ventilator](https://www.jiuyiseat.com/climate-controlled-seat/ventilated-car-seat/car-seat-ventilator.html) (IATF/ISO iddiası, OEM switch, 3 hız)
- Alibaba: “car seat ventilation kit” + **sample** (1–2 koltuk seti)
- AliExpress: aynı tip “turbo fans ventilation kit” — satıcı yorumu + video şart

### Kalite ayıracı (sipariş öncesi checklist)

```
□ “Seat cushion / embedded” — minder/cover DEĞİL
□ 3 kademe veya PWM
□ dB / RPM bilgisi var mı? (yoksa şüpheli)
□ Rocker switch OEM tip
□ Fan boyutu (kalınlık) süngere sığar mı? (tercihen ince)
□ Sample / 1 set sipariş mümkün mü?
□ IATF / ISO9001 iddiası + gerçek foto (montajlı koltuk)
□ Yorumlarda “noisy” şikâyeti oranı
```

**Kabaca maliyet (2 ön koltuk, sadece kit):**  
- Orta-iyi Çin kiti: **~150–400 USD** (gönderim+gümrük hariç)  
- TR’ye gelince + gümrük/KDV → **~8.000–20.000 TL** bandı (kur/pakete göre)  
- + döşemeci işçilik + deri delme ayrı

## 5) Önerilen sipariş stratejisi

```
1. Alibaba/AliExpress’ten 2–3 satıcıya yaz:
   “Embedded seat ventilation kit, 2 seats, 5 fans each,
    3-speed PWM, OEM rocker, low noise, sample with foam mesh”
2. Fan videosu iste (kulağa yakın, kademe 1–2–3)
3. 1 koltukluk sample → Kayseri’de usta ile deneme montaj
4. Ses/ok kabul → 2. koltuk + kalıcı montaj
5. Sessizlik yetmezse: Hyundai OEM blower (88550-…) + uyarlama Plan B
```

**Diyarbakır/Kayseri notu:** Hazır “ix35 ventilated kit” yok. Malzeme net + usta.

## 7) Çin dışı / Türkiye — gümrük istemiyorum

### Gerçekçi tablo

| Kaynak | ix35 için uygun mu? | Gümrük |
|--------|----------------------|--------|
| **TR’de hazır “ix35 ventilated kit” perakende** | **Neredeyse yok** | — |
| **TR usta / döşemeci (montaj dahil paket)** | **En iyi TR yolu** | Sen ödemezsin; usta stokundan |
| **TR’de satılan Waeco MagicComfort kılıf** | Var ama **minder/kılıf** — OEM iç montaj değil | Yok (TR stok) |
| **Mercedes W206 orijinal ısıtma/soğutma** (~30k TL) | Sadece Mercedes’e | Yok ama **arabana uymaz** |
| **Ender Elektronik Audi paneli** (72k+) | Audi odaklı, ix35 şüpheli | Yok ama pahalı/yanlış platform |
| **AB / Almanya BMW retrofit kiti** | BMW’ye özel | TR’ye yine gümrük |
| **Hyundai OEM blower ABD/EU** | Uyarlanır | Yine gümrük |

Yani: Çin’den **sen** sipariş edince gümrük var. Avrupa’dan da var.  
**Gümrüksüz** yol = **Türkiye’de zaten satılıp montaj yapılan** iş.

### Türkiye’de ne satılıyor?

**1) Waeco MagicComfort (Aes Tuning vb.)**  
- Alman/Dometic marka koltuk **soğutucu kılıf** (çakmak 12V, 2 kademe)  
- Link örneği: [aestuning.com.tr — Waeco MCS](https://www.aestuning.com.tr/waeco-magiccomfort-koltuk-sogutucu-kilif-mcs-20-mcs-10-)  
- Artı: TR stok, gümrük yok, bilinen marka, görece sessiz fan iddiası  
- Eksi: **Üstten kılıf** — senin “OEM görünsün, koltuk içine gömülü” hedefine uymaz  

**2) Marka özel paketler (Mercedes vb.)**  
- Örn. SNT Garage: Mercedes W206 orijinal koltuk ısıtma/soğutma ~**30.000 TL**  
- DRS Tuning: W206 süngerli soğutma (stok değişken)  
- Bunlar **o araca özel**; ix35’e takılmaz  

**3) Döşemeci / tuning “koltuk soğutma montajı”**  
- İstanbul/Ankara’da “sonradan koltuk havalandırma” yapan yerler var  
- Malzemeyi **onlar** getirir (çoğu yine Çin menşeli kit), sana **TL fatura + işçilik** satar  
- Sen gümrükle uğraşmazsın; fiyatın içinde ithalat payı olur  
- Bu, gümrük korkusu için **en mantıklı TR modeli**

**4) Sahibinden / yedek**  
- “Koltuk soğutma fan” araması: çoğunlukla minder veya Mercedes parçası  
- Hyundai ix35’e hazır universal embedded kit listesi **seyrek / yok**

### Pratik öneri (gümrük istemiyorsan)

```
1. Kayseri + İstanbul/Ankara döşemeci / oto elektrik:
   “Ön iki koltuk, mevcut ısıtma kalsın, delikli deri,
    iç fan (minder değil), sessiz, anahtar OEM tarzı,
    malzeme sizde, toplam TL fiyat”
2. 2–3 yerden keşif + referans foto iste
3. Fanı montajdan önce dinlet
4. Waeco kılıf = sadece “geçici / ucuz dene” Plan C (OEM değil)
```

**Çin harici “kaliteli blower kutusu” TR raftında yok** denebilir.  
Var olan TR ürünleri: (a) kılıf/minder, (b) Mercedes/Audi özel, (c) ustanın arkasındaki ithal kit.

Avrupa’dan kendin getirmek gümrüğü **çözmez** — Çin’den farkı menşei; vergi yine çıkar.
